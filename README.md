# @ktbhealth/storybook

A component catalog for the [KTB Health](https://github.com/ktbhealth) design
system. It renders every React component exported by
[`@ktbhealth/ui`](https://github.com/ktbhealth/ui) plus a growing set of
composed **Blocks** examples.

Built with Vite+ (`vp`), React 19, TanStack Router (code-based routes, SPA
mode) and Tailwind CSS v4.

## Run

```bash
bun install
bun run dev        # http://localhost:3100
bun run build      # production build to dist/
bun run check      # vp check (lint + types)
bun run format     # vp fmt
```

## Dependency on @ktbhealth/ui

The UI package is installed **from a git tag**, not npm:

```json
"@ktbhealth/ui": "github:ktbhealth/ui#v0.1.0@react"
```

The `@react` suffix selects the React build of the monorepo (`@vue` and
`@tailwind` tags exist too). Components are imported per-file:

```tsx
import { Button } from "@ktbhealth/ui/components/button";
import { cn } from "@ktbhealth/ui/lib/utils";
```

Global styles come from `@ktbhealth/ui/styles/globals.css`, which is imported
in `src/styles.css`. Because the package ships Tailwind v4 tokens and utilities
are used inside the package sources, `src/styles.css` adds `@source`
directives so Tailwind scans `node_modules/@ktbhealth/ui` — without them
classes like `bg-primary` would not be generated.

To bump the UI version, update the tag in `package.json`, run `bun install`,
then regenerate the catalog manifest:

```bash
bun run catalog:generate
```

## Catalog

`src/catalog/manifest.ts` is generated by `scripts/generate-catalog.mjs` from
the installed package. It groups components into families:

- **Core (shadcn)** — the standard shadcn-style components
- **KTB Custom** — KTB-specific components (`app-dialog`, `app-toast`,
  `attachment`, `bubble`, `message`, `questionnaire`, `trace`, `turnstile`, …)
- **AI Elements** — the `ai-elements/*` chat/agent building blocks

Component pages show a hand-written demo where one exists (`src/demos/`),
otherwise the primary export is rendered with default props inside an error
boundary. Components that need complex providers or required props will show
a setup note instead.

## Blocks

`src/blocks/` contains composed example blocks built from UI components
(patient header, consultation summary, visit history, appointment card).
All blocks are marked **WIP**.

## Notes

- Dark mode: `.dark` class on `<html>`, toggled in the sidebar and persisted
  to `localStorage` (`ktb-theme`). The ui tokens support both themes.
- Vue components (`@ktbhealth/ui/vue`) are not catalogued here; this app is
  React-only.
